# 1.4 Project Objectives

To directly address the problem statement and establish a clear project scope, CyberSight defines 5 core objectives:

1. **Objective 1 (Asset & Business Criticality Modeling):** By the end of IS 498, define and document a five-criterion business-criticality assessment model for e-commerce assets using a 1–5 rubric covering Operational Dependency, Customer Impact, Data Sensitivity, Financial Impact, and Service Availability, with a documented justification required for every assigned rating.

2. **Objective 2 (Vulnerability Data Integration):** By the end of IS 499, implement and verify a data-ingestion mechanism that imports selected CVE records and CVSS attributes from NIST NVD and enriches them with available EPSS information for the controlled e-commerce case-study dataset.

3. **Objective 3 (Explainable Business-Aware Prioritization):** By the end of IS 499, implement an explainable prioritization engine that combines CVSS severity, EPSS exploit likelihood, and Business Criticality to rank Asset–CVE risk items, while displaying the contribution of each scoring component and using stakeholder-validated or explicitly documented baseline weights.

4. **Objective 4 (Decision-Support Dashboard):** By the end of IS 499, develop a functional web-based dashboard that enables Security Analysts and IT Managers to view prioritized Asset–CVE risks, inspect score breakdowns, filter risk information by asset, severity, exploit likelihood, business criticality, and treatment status, and record basic risk-treatment status for the case-study assets.

5. **Objective 5 (Comparative Evaluation):** By the end of IS 499, evaluate CyberSight using the controlled e-commerce case study by comparing its business-aware vulnerability ranking against a CVSS-only baseline and documenting the resulting ranking differences, priority misalignment cases, and system usability findings.
